# Madan Game Store

Website statis awal untuk katalog komunitas jual beli akun game.

## File
- `index.html`: struktur halaman.
- `style.css`: tampilan responsif.
- `script.js`: katalog demo, pencarian, kategori, pratinjau iklan, dan kontak WhatsApp.
- `assets/`: tempat untuk gambar/logo tambahan.

## Publikasikan dengan GitHub Pages
1. Unggah seluruh isi folder ini ke root repository GitHub.
2. Buka Settings > Pages.
3. Pada Build and deployment, pilih `Deploy from a branch`.
4. Pilih branch `main` dan folder `/(root)`, lalu Save.
5. Tunggu publikasi selesai dan buka URL yang diberikan GitHub Pages.

## Batasan versi awal
Login Google, posting permanen, database bersama, unggah foto ke server, dan chat AI belum aktif. Pratinjau iklan hanya ada di browser saat ini. Untuk fitur bersama, sambungkan layanan backend seperti Firebase dan terapkan aturan keamanan sebelum dipublikasikan.

Jangan menaruh API key rahasia di file JavaScript publik. Periksa juga ketentuan penerbit game sebelum memperdagangkan akun.
